關於

能拿在手裡的
網路。

這個站上的網路軟體是我自己寫、自己跑的：Android 的 Hysteria 2 用戶端、 AmneziaWG 的自架面板、郵件伺服器、Markdown 筆記伺服器、包在 headscale CLI 外面的一層，以及用官方原始碼編出來的 OpenWrt 映像。每一件都先是自己基礎設施的一部分， 然後才是別的東西。

它們都照兩條規則做。第一，跑在操作者自己的機器上：中間沒有代管帳號，沒有分析、沒有遙測， 也沒有任何「別人的伺服器一關就不能用」的部分。第二，小到可以從頭讀完：磁碟上是普通檔案， 用標準協定，相依套件固定版本並把雜湊留在倉庫裡。

這裡全部開源，MIT 或 AGPL-3.0，各專案頁上寫得清楚。原始碼、issue 與發佈都在 GitHub，文件跟它所描述的程式放在同一個倉庫。

某個專案有 bug 或疑問，就開那個 repo 的 issue——Hy2droid 的 bug 表單會問版本與第一個 失敗的步驟，可以省一輪往返。其他事情，從 GitHub 個人頁找我。

純靜態頁面。軟體自己架或自己側載，原始碼、issue 與發佈都在 GitHub； 第三方授權列在各專案裡。
