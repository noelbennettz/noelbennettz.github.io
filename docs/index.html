Flow Notes

A note server you run yourself: every note is a plain Markdown file, the folders on disk are the sidebar, and SQLite FTS5 is an index you can rebuild. The editor runs offline, with no CDN and no web fonts. Needs Docker, or Python 3.11 for a manual install.

Questions

Do the self-hosted services speak HTTPS?

No. Flow Notes, iMail and the AmneziaWG panel listen on plain HTTP — Flow Notes on port 8000, iMail on 80 and 443 only after its own ACME setup, AmneziaWG on its chosen port. Their session cookies are HttpOnly and SameSite=Lax but not Secure, which is what lets a LAN address such as http://192.168.1.10:8000 sign in. Keep those ports on the LAN and terminate TLS in front before exposing anything to the internet.

How do I put a reverse proxy in front?

With Caddy it is two lines: notes.example.com { reverse_proxy 127.0.0.1:8000 }. With nginx, proxy_pass http://127.0.0.1:8000; plus proxy_set_header Host $host;, and raise client_max_body_size to at least 21m so 20 MB image uploads are not rejected. No WebSocket upgrade and no rewrite rules are needed, and binding the container to 127.0.0.1:8000 keeps the plain port off the network.
