Hy2droid

An Android app that connects your phone to a Hysteria 2 server — one you run, or one whose share link you were given. Paste the link or scan a QR code, and the phone's traffic goes out through that server. Needs Android 11 or newer; no root and no Google account.

AmneziaWG Web UI

A web page for running your own AmneziaWG VPN server, shipped as one ~41 MB Docker image: create servers and clients, export .conf, QR or vpn:// links, and watch traffic. Needs a Linux host with Docker, Compose 2.24 or newer and a public IPv4 address.

iMail

A mail server for your own domains: SMTP, IMAPS and POP3S, a browser inbox, an admin console and per-domain certificates. Needs Docker, a domain you control, and port 25 open at your provider.

Flow Notes

A note server you run yourself: every note is a plain Markdown file, the folders on disk are the sidebar, and SQLite FTS5 is an index you can rebuild. The editor runs offline, with no CDN and no web fonts. Needs Docker, or Python 3.11 for a manual install.

hs

A wrapper around the headscale CLI that turns --identifier <id> into names you can type: hs show laptop, hs expire phone, hs route add gw 10.0.0.0/8. Bash and jq, no daemon, no config file, and no state of its own — every command reads what it needs from headscale and exits. Needs jq and the headscale binary on the same server.

OpenWrt x86

An OpenWrt 25.12 image for x86/64 built from official sources on GitHub Actions, with the whole configuration in one .diffconfig: Passwall with sing-box and Hysteria 2, seven languages, 92 network drivers. A run publishes the images as an artefact and a release. Nothing to install locally — fork it, run the workflow, write the image to disk.
