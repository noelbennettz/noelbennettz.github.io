About

Networks I can
hold in my hands.

I write and run the network software indexed on this site: a Hysteria 2 client for Android, a self-hosted panel for AmneziaWG, a mail server, a Markdown note server, a wrapping layer over the headscale CLI and an OpenWrt image built from official sources. Each of them was a piece of my own infrastructure before it was anything else.

Two rules shape all of them. The software has to run on hardware its operator owns: no hosted account in the middle, no analytics, no telemetry, and nothing that stops working the day someone else's server is turned off. And it has to stay small enough to read end to end — plain files on disk, standard protocols, dependencies pinned with their hashes in the repository.

Everything here is open source, MIT or AGPL-3.0, stated on each project's page. Source, issues and releases live on GitHub; the documentation ships in the same repository as the code it describes.

For a bug or a question about one project, open an issue on that project's repository — the Hy2droid bug form asks for the version and the first step that failed, which saves a round trip. For everything else, the GitHub profile is the way to reach me.
